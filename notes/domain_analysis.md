# SAA-C03 Exam Domains Analysis

## Goal Description
Provide the user with a clear understanding of the AWS Certified Solutions Architect - Associate (SAA-C03) exam structure and how their specific repository aligns with these goals.

The core of your study material is the [AWS SAA-03 Solution.md](../AWS%20SAA-03%20Solution.md) file, which contains hundreds of practice questions with detailed explanations. These questions map directly to the four official exam domains.

## Exam Domains Overview
The exam is structured around four key domains:

1.  **Domain 1: Design Secure Architectures (30%)**
    *   **Focus**: IAM, VPC security (NACLs, Security Groups), data encryption (KMS, CloudTrail), and regulatory compliance.
    *   **Study Tip**: Pay close attention to questions about granular access and auditable encryption.

2.  **Domain 2: Design Resilient Architectures (26%)**
    *   **Focus**: Multi-tier architectures, high availability (Multi-AZ), disaster recovery, and decoupled systems (SQS, SNS).
    *   **Study Tip**: Look for keywords like "highly available" and "fault-tolerant."

3.  **Domain 3: Design High-Performing Architectures (24%)**
    *   **Focus**: Performance optimization (Provisioned IOPS, Read Replicas), caching (CloudFront, ElastiCache), and serverless scaling.
    *   **Study Tip**: Focus on storage throughput and database read/write bottlenecks.

4.  **Domain 4: Design Cost-Optimized Architectures (20%)**
    *   **Focus**: Choosing the right storage tier (S3 Intelligent-Tiering), Spot vs. Reserved Instances, and serverless cost benefits.
    *   **Study Tip**: Target "minimal cost" and "unpredictable access" requirements.

# SAA-C03 Exam Domains Analysis

## Goal Description
Provide the user with a clear understanding of the AWS Certified Solutions Architect - Associate (SAA-C03) exam structure and how their specific repository aligns with these goals.

## Exam Domains Overview
The exam is structured around four key domains:

1. **Domain 1: Design Secure Architectures (30%)**
   - Focus: Identity and Access Management (IAM), VPC security (Security Groups, ACLs), encryption at rest/transit (KMS, TLS), and regulatory compliance.
   - *Dump Example*: Question 11 (Secrets Manager), Question 15 (Network Firewall), Question 44 (MFA Delete).

2. **Domain 2: Design Resilient Architectures (26%)**
   - Focus: High availability, multi-tier architectures, disaster recovery, and decoupled systems.
   - *Dump Example*: Question 5 (EFS for shared storage), Question 7 (SNS/SQS decoupling), Question 14 (Aurora Replicas).

3. **Domain 4: Design High-Performing Architectures (24%)**
   - Focus: Performance optimization across compute (Auto Scaling), storage (EBS types), database (Read Replicas), and network (CloudFront).
   - *Dump Example*: Question 1 (S3 Transfer Acceleration), Question 12 (CloudFront distribution), Question 39 (Provisioned IOPS).

4. **Domain 4: Design Cost-Optimized Architectures (20%)**
   - Focus: S3 storage classes (Glacier, Intelligent-Tiering), compute savings (Spot, Reserved Instances), and right-sizing.
   - *Dump Example*: Question 9 (Glacier Deep Archive), Question 22 (Intelligent-Tiering), Question 32 (S3 Static Hosting).
